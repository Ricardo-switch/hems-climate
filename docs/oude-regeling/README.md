# De oude regeling

Het YAML-systeem in Home Assistant dat SunArc vervangt, als naslag (besluit 236).

- `legacy_code/`: een momentopname van de automatiseringen, scripts en helpers, van vóór de reparaties (besluit 15 en verder).
- `ha-fixes/`: de reparaties aan het script dat alles toepast, `klimaat_controller_apply`. Daaruit blijkt bijvoorbeeld wanneer de oude regeling een airco op warm zet, en wanneer een knop met de hand voorgaat (besluit 235).

Tot stap B regelt dit systeem het huis, en kijkt SunArc mee. De vergelijking tussen de twee is het bewijs voor het echte regelen (besluit 64).
