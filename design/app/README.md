ontwerp 2 in `design/app2/` (besluit 104), waar de schets de code is.

21 oktober 2026 weggehaald: ze maakten de repository 29 MB groter, en Home
Assistant haalt de repository op bij het toevoegen van de add-on. Ze staan nog
in de geschiedenis van git, in de commits van vóór die datum.

Wat blijft is [ONTWERP.md](ONTWERP.md): hoe het samenhangt en wat vastligt. De
code verwijst er nog naar met "ONTWERP §".
